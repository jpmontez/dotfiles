# Cross-Platform Dotfiles Design

**Date:** 2026-03-28
**Platforms:** macOS (primary), Windows 11 + WSL 2 (Ubuntu)

## Goal

Migrate the dotfiles from a Python `dotfiles` package + Dropbox sync setup to a git repository managed with GNU stow, with full compatibility on both macOS and WSL 2. A single `bootstrap.sh` script handles setup on any supported platform from scratch.

---

## Repository Structure

Each tool gets its own stow package (a top-level directory). Running `stow <package>` from inside the repo creates symlinks in `~` that mirror the package's directory tree.

```
dotfiles/
├── .gitignore
├── .gitmodules
├── bootstrap.sh
│
├── zsh/                        # stow package
│   ├── .zshrc
│   ├── .zprofile
│   └── .aliases
│
├── git/                        # stow package
│   └── .gitconfig
│
├── tmux/                       # stow package
│   └── .tmux.conf
│
├── ssh/                        # stow package
│   └── .ssh/
│       └── config
│
├── shell/                      # stow package (misc shell config)
│   └── .dotfilesrc
│
├── nvim/                       # stow package
│   └── .config/
│       └── nvim/               # git submodule → jpmontez/kickstart.nvim
│
├── iterm2/                     # stow package (macOS only)
│   └── .config/
│       └── iterm2/
│
└── zprezto/                    # git submodule → jpmontez/prezto
```

**Git submodules:**

| Directory | Repository |
|---|---|
| `zprezto/` | `https://github.com/jpmontez/prezto.git` |
| `nvim/.config/nvim/` | `https://github.com/jpmontez/kickstart.nvim.git` |
| `config/base16-shell/` | upstream `https://github.com/chriskempson/base16-shell.git` (not a stow package — referenced directly from `zshrc`) |

**Dropped in migration:**
- `bashrc` / `bash_profile` — bash is secondary; not tracked
- `zpreztorc` / `zshenv` symlinks — managed by the zprezto submodule
- `config/argocd/`, `irssi/`, `config/rclone/` — deleted entirely
- Dropbox conflicted copies — cleaned up

## Platform Detection

A `uname` check is the single detection mechanism used consistently across shell configs and the bootstrap script.

**`zsh/.zprofile`** — wrap Homebrew setup in a macOS guard:
```zsh
if [[ "$(uname)" == "Darwin" ]]; then
  eval "$(/opt/homebrew/bin/brew shellenv zsh)"
fi
```

**`tmux/.tmux.conf`** — use tmux's `if-shell` for clipboard copy binding:
```tmux
if-shell "uname | grep -q Darwin" \
  "bind-key -T copy-mode-vi y send -X copy-pipe-and-cancel 'reattach-to-user-namespace pbcopy'" \
  "bind-key -T copy-mode-vi y send -X copy-pipe-and-cancel 'xclip -in -selection clipboard'"
```

**`ssh/.ssh/config`** — add `IgnoreUnknown UseKeychain` at the top to suppress the Linux warning for the macOS-only directive:
```
IgnoreUnknown UseKeychain
```

Everything else (`gitconfig`, `aliases`, `zshrc`) is already platform-agnostic.

## Bootstrap Script

`bootstrap.sh` runs top-to-bottom and is idempotent (safe to re-run). Stow uses `--restow` so re-running updates symlinks rather than erroring on existing ones.

```
1. Detect platform (macOS or Linux/WSL)

2. Install dependencies
   macOS  → install Homebrew if missing → brew install stow zsh tmux neovim
   Linux  → sudo apt update → apt install stow zsh tmux neovim xclip

3. Init git submodules
   git submodule update --init --recursive

4. Stow shared packages
   stow zsh git tmux ssh shell nvim

5. Stow platform-specific packages
   macOS  → stow iterm2
   Linux  → (none currently)

6. Set zsh as default shell if not already
   chsh -s $(which zsh)

7. Print next steps
   - "SSH keys not set up — generate or copy manually"
   - "Re-authenticate gh CLI: gh auth login"
```

**Usage on a fresh machine:**
```sh
cd ~/Development
git clone --recurse-submodules https://github.com/jpmontez/dotfiles.git
cd dotfiles
./bootstrap.sh
```

## Secrets Strategy

Secrets are never tracked in git. Each is either regenerated on the new machine or transferred out-of-band.

| Secret | Strategy |
|---|---|
| SSH private keys (`id_*`) | Generate fresh per machine or copy securely |
| GitHub CLI token (`config/gh/hosts.yml`) | Regenerated by `gh auth login` |
